# Coffee Sales Dashboard

A concise project for analyzing coffee shop sales with a Power BI dashboard, a SQL exploration script, and the raw data files.

## Project Contents

- `coffee sales dashboard.pbix` — Power BI dashboard file.
- `coffee sql solution.sql` — SQL queries used to explore/transform the data.
- `Coffee Shop Sales.csv` — Primary dataset (CSV).
- `Coffee Shop Sales.xlsx` — Primary dataset (Excel).
- `2632464.jpg` — Reference image (if used for visuals or context).

## Data

The dataset includes coffee shop sales records suitable for time-series analysis and product/category performance insights. Use the CSV or Excel file as the data source when refreshing the Power BI report.

## How to Use

### Power BI Dashboard

1. Open `coffee sales dashboard.pbix` in Power BI Desktop.
2. If prompted, update the data source path to point to `Coffee Shop Sales.csv` or `Coffee Shop Sales.xlsx`.
3. Refresh the dataset to load the latest data.

### SQL Exploration

1. Open `coffee sql solution.sql` in your SQL editor.
2. Load the dataset into your SQL environment (or update table references as needed).
3. Run the queries to reproduce the analysis steps used for the dashboard.

## Notes

- File names are preserved as provided. If you relocate the dataset, update the Power BI data source settings accordingly.
- The dashboard is intended as a starting point; you can extend it with additional visuals or measures.
